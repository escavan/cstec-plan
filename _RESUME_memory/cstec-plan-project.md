NSR(국가보안기술연구소) 사이버안보훈련센터(CSTEC)의 교육로드맵을 AI 시대에 맞게 혁신하여, **2027년 개소 예정 K-사이버훈련원**의 내부 교육·훈련 콘텐츠 체계를 새로 설계하는 프로젝트. (마지막 작업: 2026-05-26)

## 범위·대상
- **우리 부서 범위**: 이론 + 이론이해용 실습(Hands-on) + Training. **Exercise(도상훈련·실전 모의침투·레드/블루팀 CTF)는 타 부서 → 제외**(매트릭스엔 위치만 표시).
- **주 대상**: 국가·공공기관 보안 담당자 + 정보화 실무자. **부 대상**: 지역대학생·여성대학생·지역기관(특별과정).
- **작업방식**: Markdown 작업초안 → 확정 후 Word/Excel/PPT 변환. 용어 설명은 본문 해당 위치 바로 아래 `💡 용어 설명` inline 박스.

## 확정된 설계 결정
- **2층 구조**: 분야 → 직무군 × 레벨.
- **2개 분야**: ① 일반 사이버보안 교육 ② AI보안 교육.
- **레벨 3단계**(NICE Entry/Inter/Advanced 정합) + **난이도 띠 하향**: 초급=인식/입문(70:30, AI인식형 80:20), 중급=표준 실무(40:60), 고급=심화 실무(30:70). 연구·개발급(커스텀 익스플로잇·APT리버싱 심화·적대적공격 연구 등)은 **범위초과→타부서/향후**. 고급 4원칙: 도구사용≠개발 / 운영산출물 지향 / 표준프레임워크 매핑 / 산출물 평가.
- **일반 사이버보안 6직무군**(국내 5기능 + NICE OV·SP 보완): J1 정책·거버넌스, J2 보안설계·도입, J3 예방, J4 탐지, J5 분석, J6 대응(초동대응 통합).
- **AI보안 4직무군**(모래시계형): AISA 분석·방어(트랙1 보안인력), AISG 운영·거버넌스(수렴), GAID 생성형AI 구축실무(트랙2 실무자), AITR 위협대응·인텔리전스(가교).
- **과정 카드 양식**: ETRI(1과목=1페이지 카드) + CDSA(직무·레벨 매핑, 선수→후속 Pathway) 융합.

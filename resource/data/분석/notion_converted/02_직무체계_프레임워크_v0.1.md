# 직무체계 + 단계별 커리큘럼 프레임워크 (v0.1)

> **문서 위상**: [01_교육체계_기본설계서](01_교육체계_기본설계서_v0.1.md)의 §4(체계 골격)를 **직무 기반으로 구체화**한 실무 설계서. 후속 산출물(과정 카탈로그·실라버스)이 이 직무군·레벨 매트릭스를 따른다.
>
> **설계 결정 (확정)**: 레벨 3단계(초급/중급/고급, NICE Entry/Intermediate/Advanced 정합) · 2개 분야(일반 사이버보안 / AI보안) 동시 설계 · 일반 직무군은 국내 5기능에 가깝게 하되 NICE로 보완 · 2층 구조(분야 → 직무군 × 레벨) · 부서 범위 = 이론 + 이론이해용 실습 + Training (Exercise는 타부서, 위치만 표시).
>
> **근거 자료**: NIST SP 800-181r1(NICE), CISA CDSA FY25 Course Catalog, 국내 "사이버보안 기술적 대응 직무역량 프레임워크 제안", 해외 교육체계 분석 보고서, 사이버안보훈련센터 2026 연간 운영계획.

## 0. 설계 철학 — "최대한 간략화한 NICE"

NICE Rev.1은 이미 **스스로 간략화**되어 있다. 2017판의 7개 Category·33개 Specialty Area를 **폐기**하고 `Work Role + Task/K&S + Competency`의 모듈식으로 재편했으며, **숙련도 레벨은 의도적으로 정의하지 않는다**(조직이 별도 모델로 적용하도록 위임). 따라서 우리의 간략화 원칙은:

<table fit-page-width="true" header-row="true">
<tr>
<td>유지</td>
<td>간소화/대체</td>
<td>제거</td>
</tr>
<tr>
<td>**직무군(Work Role group)** — 교육·평가의 묶음 단위</td>
<td>Task/K&S → 과정의 "교육내용"으로 자연 표현</td>
<td>Category·Specialty Area (NICE도 폐기)</td>
</tr>
<tr>
<td>**레벨(초/중/고)** — 별도 모델로 정의</td>
<td>Competency → "수료·배지"로 단계적 도입</td>
<td>Ability (NICE는 Skill로 통합)</td>
</tr>
</table>

→ 결과적으로 우리 체계의 최소 골자는 **`직무군 × 레벨` 2축 매트릭스**이며, 각 셀에 과정(과목)이 배치된다.

> 💡 **용어 설명 — NICE 구성요소**
> - **Work Role(직무)**: 책임·업무의 묶음(예: 사이버방어 분석가). 우리의 '직무군'이 이에 해당.
> - **Task(과업)**: 직무가 수행하는 구체 활동.
> - **Knowledge & Skill (K&S, 지식·기술)**: 과업 수행에 필요한 지식과 기술.
> - **Competency(역량)**: Task 또는 K&S의 묶음으로, 학습자를 평가하는 단위.
> - **Ability(능력)**: 옛 NICE의 항목 — 개정판이 Skill로 통합·폐기.

## 1. 전체 구조 (2층)

```
K-사이버훈련원 교육체계
│
├─ [분야 1] 일반 사이버보안 교육
│     직무군 6개(J1~J6) × 레벨(초급/중급/고급)
│     └ 국내 5기능(예방·탐지·분석·대응) 골격 + NICE 보완(J1 정책·거버넌스 / J2 보안설계·도입)
│
└─ [분야 2] AI보안 교육
      직무군 4개(AISA·AISG·GAID·AITR) × 레벨(초급/중급/고급)
      └ 양방향 인재상(보안인력 ↔ 실무자) "모래시계형" 배치
```

- **1층(분야)** = [01 기본설계서]의 2 대분류를 계승: AI보안 / 일반 사이버보안.
- **2층(직무군 × 레벨)** = 본 문서의 핵심. NICE 직무 기반.
- **레벨 체계는 두 분야 공통**이라 학습자가 분야를 넘나들어도 수준이 호환된다(양방향 교육의 기반).

## 5. 설계 핵심 논리 (요약)

1. **간략화**: NICE Rev.1이 이미 폐기한 Category/Specialty를 따라 버리고, `직무군 × 레벨` 2축만 남겨 현행 과정을 그대로 담는다.
2. **일반 분야**: 국내 5기능을 골격(예방·탐지·분석·대응)으로 유지하되, 5기능이 못 담는 NICE의 OV·SP를 J1·J2로 보완 → 사고 전·중·후 전주기 6직무군으로 닫힘.
3. **AI 분야**: 양방향 인재상을 가로축 양 끝(분석·방어 ↔ 구축실무)에 두고 거버넌스·위협대응을 가운데서 수렴시키는 모래시계형.
4. **레벨**: 70:30 → 40:60 → 30:70로 이론:실습을 차등해 "이해 → 수행 → 분석" 학습곡선을 명시하고, Exercise(타부서)는 고급 외곽에 위치만 표시.
5. **가시화된 우선순위**: 일반은 J4·J5·J6 중·고급, AI는 AISA 중·고급이 최우선 신규 개발 대상.
